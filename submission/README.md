# Submission materials

This directory contains the judge-facing slide deck and submission copy for **Casework**. The technical guide lives in [architecture](../architecture/README.md).

- [Project description and submission checklist](project-description.md)
- `Casework-Submission.pptx`: editable presentation, added after visual review
- `Casework-Slide-Preview.pdf`: readable slide preview, if the available exporter supports it
- Fresh [board](../architecture/media/investigation-board.jpg), [voice interview](../architecture/media/voice-interview.jpg), [partner](../architecture/media/detective-partner.jpg), and [catalog](../architecture/media/case-catalog.jpg) screenshots

The deck is designed for self-contained judging, with character voice interaction and the detective partner as its main product highlight. It covers technology integration, presentation, practical value and originality. Business opportunities are hypotheses rather than claims of user traction.

The application URL and presentation video are separate submission fields. A temporary local callback tunnel is not a substitute for a hosted demo URL. No video recording or public-deployment completion is claimed by these materials.
